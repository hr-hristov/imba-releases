Apps

One app for every server

The desktop, Windows, Android and iPhone apps ask for your server's address when they first start, then load imba from that server and follow its upgrades. Settings, Server shows the address and changes it.

Automations

Routines and automation chats on the spawn list

Routines and standing chats now sit on the automations row at the foot of Spawns. Each routine run starts its own spawn. An automation chat stays open, and Done closes each round until the next one.

Context

See what fills a spawn's context

Press the context gauge in a spawn's header for a bar of what fills its context window, part by part, as Claude Code's /context draws it. Press it again to hide the bar.

State

Ask a spawn where it stands

The State button, or c, asks the agent for a card: the goal, what is done, what is left, what needs you, and pictures of the screen before and after.

Log

Read and copy a past prompt

Pick a turn in a spawn's Log to read the prompt you sent then, open it in full, and copy it.
