Update from Settings, Upgrade
State

Where a spawn stands, always in view

The top of every turn's Edits box now says what the work is for, and a track along it shows how far the spawn has come, from Investigating to Finished, with the count waiting on you. It is always there, with nothing to switch on: the newest turn's track opens the State card, or press c, and every Ultrafocus line carries the same stage.

Ultrafocus

Pull requests in New

Ultrafocus New lists each project's open pull requests under it, with who opened them. Pressing one opens a new spawn that merges it, and once that spawn starts the pull request leaves New.

Logins

Spread the spawns over every login

Spread on the Agent usage panel, or e, evens the running Claude spawns out over every login, by the room each one has left this week. It shows each login's count now and after, moves idle spawns first, and says where each one landed.

Apps

Every app from Settings

Settings, Apps lists the newest desktop, Android and iPhone builds, with a Download for each and an install link for the iPhone. The files come through your server, so no Git sign-in is needed, and Check now looks again.

Machine

A housekeeping agent for the machine

Settings, Housekeeping runs an agent every few hours against goals for disks, cores and swap. It stops idle copies of your apps and clears old containers and images, and what only you can do lands under Needs you, where Investigate starts a spawn on it.

Also

  • A spawn running on a Claude login that ends within the week says so above its chat, with Renew login and Hide until tomorrow
  • The Log keeps every turn that ended on a plan, named by its plan
  • The State card has four more stages, Investigating, Ready, Paused and Moved, and a halted spawn stands on the stop it reached
  • A star on the reply being read stars its turn
  • A task's repository is picked from every Git connection at once, with no connection to choose first
  • Builds, films and test runs from every spawn take turns on the machine, so one heavy job no longer slows the rest
  • A helper agent that would copy the whole conversation is refused, and a stopped helper wakes only within the helper limit
  • Fixes: the Windows app freezing after a page loads, spawns sitting on a spent login, Move all here stopping partway over many spawns, login moves stalling on Claude's folder question, and a push shown twice on the phone

Recorded in imba. Every spawn, repository and person in these films is made up.
